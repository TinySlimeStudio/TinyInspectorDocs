# Roadmap

{% hint style="warning" icon="map" %}
This is more of an idea of what to expect in the future than a complete roadmap.
{% endhint %}

### <i class="fa-wrench">:wrench:</i> Version 1.0.X

Depending on the number of problems and inconveniences after the release, patches may be released to fix bugs and glitches.

> (I tested the package on 2022.3, 2023.3, 6.0, and 6.3, but I may have missed something.)

### <i class="fa-pen-ruler">:pen-ruler:</i> Version 1.1.0

For the first major update, I plan to add support for several non-serializable classes such as:

* Timespan
* DateTime
* Big Integer
* GUID
* Verison

and for Dictionary\* (Unfortunately, due to Unity limitations, to display Dictionary in the Inspector, you will need to use TinyDictionary, which contains dictionary).

### <i class="fa-rocket">:rocket:</i> In the future

I don't have the rest of the changes defined yet, but these are ideas that I would like to implement as soon as possible.

#### **Attributes**

* Indent
* GUI Color
* Steps
* Value Dropdown
* Animator Parameters
* Material Parameters
* Path Picker
* Reset Button
* Scene Objects Only
* Asset Objects Only
* Child Object Only
* Read Only
* Inline Editor
* Custom Context Menu
* and Many Many More...

#### Editors

I currently have a good idea for one editor, but there will be many more.

\- **Scriptable Object Manage**r - Allows you to find all scriptable objects and display them in a single editor, divided into classes, with a simple option to find their location and edit them

#### New Functions

I don't want Tiny Inspector to be a simple asset with attributes, but something bigger. I want it to offer more possibilities in terms of customization and engine functionality.

Here are the things I plan to add at the moment:

* Object Notes
* Hierarchy Title & Separators
* Searchable Context Menu
* New UI Elements: Tabs, Selectors
* New Gizmo Drawers
* and Many More...
