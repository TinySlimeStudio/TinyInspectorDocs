# Player Prefs Manager

{% hint style="info" icon="list" %}
To open this editor in the toolbar, select <mark style="color:$primary;">Tools > Tiny Inspector > Tools > PlayerPrefs Manager</mark>
{% endhint %}

<figure><img src="../.gitbook/assets/Zrzut ekranu 2026-02-19 011615 (2).png" alt=""><figcaption></figcaption></figure>

The editor provides a clean and intuitive overview of all saved Player Prefs, including those automatically generated by Unity. Values are intelligently grouped by their respective data types, making navigation effortless and data analysis more efficient. This organized layout allows you to quickly locate, review, and manage your preferences with clarity and precision.

### <i class="fa-pencil-line">:pencil-line:</i> Edit Player Prefs Value

<figure><img src="../.gitbook/assets/Zrzut ekranu 2026-02-19 012105.png" alt=""><figcaption></figcaption></figure>

The editor allows you to seamlessly modify Player Prefs with built-in automatic validation, ensuring that all changes adhere to the correct data types and formats. This intelligent safeguard effectively eliminates the risk of accidentally corrupting or introducing errors into your saved data, providing a safe and reliable editing experience.

### <i class="fa-square-plus">:square-plus:</i> Create new Player Prefs

<figure><img src="../.gitbook/assets/Zrzut ekranu 2026-02-19 011916.png" alt=""><figcaption></figcaption></figure>

You can effortlessly add new Player Prefs directly through the editor, eliminating the need to define them in code. This streamlined approach simplifies the process and offers greater flexibility in managing your project's saved data.
