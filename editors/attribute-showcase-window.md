# Attribute Showcase Window

{% hint style="info" %}
To open this editor in the toolbar, select <mark style="color:$primary;">Tools > Tiny Inspector > Attribute Showcase</mark>
{% endhint %}

<figure><img src="../.gitbook/assets/Zrzut ekranu 2026-02-19 010117.png" alt=""><figcaption></figcaption></figure>

The editor allows you to browse all available attributes and quickly search for a specific one using the search field located in the top-left corner.

When an attribute is selected, its name and description are displayed on the right-hand side.

Below, an interactive demo showcases the attribute's functionality and appearance.

At the bottom, you'll find the source code for the interactive demo, which you can easily copy and integrate into your own projects.
