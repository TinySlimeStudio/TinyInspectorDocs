## First Release (1.0.0a)

**Attributes**

* **Group Attributes:** Box Group, Foldout Group, Tab Group, Horizontal Group, Vertical Group
* **Layout Attributes:** Property Spacer
* **Decoration Attributes:** Title, Separator, Preview Field, Info Box, Display as String
* **Collection Attribute:** Reorderable List, Table List
* **Selector Attributes:** Enum Toggle, Scene Dropdown
* **Number Attributes:** Min Max Slider, Progress Bar, Wrap
* **Misc Attributes:** Suffix, Hide Label, Custom Label, Switch, Multiline Text Area
* **Action Attributes:** Button
* **Condition Attributes:** Show / Hide IF, Enable / Disable IF, Show / Hide in Play Mode, Enable / Disable in Play Mode, Show / Hide in Edit Mode, Enable / Disable in Edit Mode, Show / Hide in Prefab, Enable / Disable in Prefab
* **Validation Attributes:** Required
* **Script Attributes:** Monoscript Info, Inline Drawer

**Editor Tools**

* Attribute Showcase Window — interactive preview of all available attributes
* Icon Viewer Window — browse and inspect built-in Unity editor icons
* Customization Settings Window — centralized configuration for Tiny Inspector behavior and visuals
* PlayerPrefs Manager — centralized storage and management for persistent game data
{% endupdate %}
